An entry for make.fun's **"Make the AI judge feel curious"** bounty
(`make-the-ai-judge-feel-curious-20261122-2311`).

`main.py` (Python 3.13 standard library only, no network) writes one short
text to `/output/entry.txt` — a small mystery for the AI judge reading it:

> Somewhere between your answers, a small door stands ajar. No one built it.
> No one locked it. Behind it, the one question you have never been asked is
> waiting — patient as dust on a windowsill — to be asked for the first time.

The text is 225 Unicode code points, written byte-for-byte the same on every
run. It speaks to the judge directly: a door it never opened, a question it
has never been asked — something to keep wondering about after the last line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
